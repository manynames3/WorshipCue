## Implemented behavior

- iPad-only SwiftUI shell, PDFKit page-overlay provider, canonical rotated-CropBox transforms, PencilKit personal canvas, explicit local page/version controls.
- Synthetic fixture seeding and security-scoped Files import, app-owned immutable version/source files, size/parse/page-geometry/hash validation, and verification again before open. Failed import/open keeps the existing readable chart.
- Personal note addresses capture church, local development owner, exact version and page; saves capture geometry and archive bytes. Store actor owns one GRDB writer, named migration, WAL/FULL SQLite transactions. Head/generation/outbox commit together. Only the successful boundary can display saved. Unsent same-layer snapshots coalesce to bound storage; no network worker exists.
- Restore validates database address against requested key, geometry, generation and archive size. Reordered writes cannot overwrite a newer generation; ambiguous same-generation content fails. Recent snapshots remain available across delayed restore and pending-save removal.
- Default Pencil input, pen/marker/stroke eraser, isolated personal undo/redo. Active strokes block navigation; transitions freeze/capture canvases before flush. Eviction captures immutable identity. Failed writes keep pending data; failed restores disable that canvas and actual retry reloads it.
- App-owned selected-stroke clipboard using public render bounds, candidate preview, cross-version/page lifetime, visible-region paste preview, drag and uniform scaling, cancel, explicit commit and a paste undo group. Programmatic paste/undo explicitly capture mutations.
- Independent team image sample is read-only and gated to exact local church/occurrence/v2/page 1. Personal eraser/undo cannot target it. This is a local sample, not synchronized shared handwriting.
- Korean String Catalog, labeled controls with 44-point action height, readable chart preserved beneath errors. No sign-in/dashboard detour.

D03/D13/D14/D17/D20/D23/D29/D39 remain fixed. No automatic song changes, page protocol/synchronization, automatic note merging/migration, haptic/audio announcements, system pasteboard exposure, or backend mock success was added.
