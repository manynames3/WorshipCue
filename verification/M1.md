# M1 · Local weekly music stand

Implemented 2026-10-07–08. This is a local development slice, not an end-user release or a qualified rehearsal pilot. M0 physical Pencil/oldest-device gates and M2–M6 remain open.

## Implemented behavior

- Korean title/initial/alias/hymn-number search, hymn edition metadata and favorites.
- Immutable, transactionally numbered chart versions. Opening a chart and setting a personal preference are independent actions. Bookmarks are per version.
- New-song/new-version PDF import with hash, byte-count and every-page geometry validation, protected atomic file write, read-back verification, then catalog publication.
- One-time transactional legacy JSON migration into GRDB SQLite. Chart UUIDs, original PDF bytes, personal ink database and owner/version/page identities stay intact. The old JSON remains a receipt.
- Manual inclusive page-range extraction from weekly packets into separately verified PDFs. Embedded arranger annotations are preserved; ranges and source asset IDs are retained. A failed batch publishes no partial versions.
- Local setlist create/edit/reorder/clone, separate planned/standby entries, repeated songs with distinct occurrence UUIDs, exact version and performance-key choices. Revision checks and composite song/version foreign keys reject stale or mismatched writes.
- Local preflight checks selected, preferred and standby PDFs without changing the open reader. It reports file availability, not network/team readiness.
- Explicit selected-personal-note destination/version/page chooser; draggable/scalable preview and separate confirm/cancel/undo. No automatic transfer or merge.
- New fallback PDF with original/arranger content and optionally this local owner's personal ink; native share sheet. Export never overwrites a source. The local team demonstration is excluded.
- Korean String Catalog and accessible controls. No new production dependency, cloud account, billing, paid Apple enrollment or live protocol was added.
