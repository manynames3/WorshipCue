# 제품 요구사항 · 파일럿 v1

## 1. 목표와 전제
첫 팀이 실제 리허설과 예배에서 iPad 악보장으로 사용할 수 있어야 합니다. 밴드마스터는 건반을 연주하며 곡을 선택하거나 인도자에게 미리 곡을 전달받습니다. 팀원은 자기 필기와 선호 악보 버전을 유지합니다. 이는 이 팀을 위한 설계 전제이지, 모든 한국 교회의 운영 방식에 대한 주장이나 시장 검증 결과가 아닙니다.

핵심 가치는 **악보 수정 후에도 내 필기가 남는 신뢰**와 **즉흥곡 안내를 놓치지 않으면서 화면 선택권을 유지하는 것**입니다. 음향, 녹음, 교회 행정은 다루지 않습니다.

## 2. 사용자와 권한
| 역할 | 할 수 있는 일 | 할 수 없는 일 |
|---|---|---|
| 교회 관리자 | 팀/멤버/초대 관리, 콘티와 악보 관리, 진행권 인계 | 다른 사람 개인 필기 열람, 비공개 자료의 교회 간 공유 |
| 밴드마스터 | 콘티 작성, PDF/버전 등록, 대기곡 준비, 진행권 보유 시 곡 안내와 팀 필기 | 진행권 없이 공유 레이어 변경, 팀원 화면 강제 변경 |
| 연주자 | 콘티 보기, 개인 필기, 버전 선택, 수동 곡 열기, 팀 필기 보기 | 공용 원본 변경, 임의 곡 안내, 다른 사람 개인 필기 열람 |
| 게스트 | 허용된 예배/대기곡 보기, 해당 기기 개인 필기, 수동 곡 열기 | 전체 교회 라이브러리 검색, 팀 필기 편집, 회원 관리 |

교회는 과금/콘텐츠 격리 단위이고 팀은 교회 안의 권한/콘티 단위입니다. 첫 교회 생성 시 기본 찬양팀 하나를 생성합니다. 멀티팀 관리 화면은 후순위지만 ID/권한 구조는 처음부터 분리합니다. 교회 관리자는 라이브러리를 관리할 수 있으나 실제 곡 안내에는 명시적 진행권이 필요합니다.

## 3. 핵심 기능과 수용 기준

### F01. 악보 가져오기
개별 PDF는 제목, 표기 키, 선택적 편곡 설명을 확인합니다. 묶음 PDF는 페이지 썸네일에서 시작/끝 범위를 지정해 곡을 나눕니다. 원본 묶음은 보관하고 곡별 PDF를 별도 불변 파일로 생성합니다. 빈 표지/광고 페이지는 제외할 수 있습니다. 한 원본 범위를 여러 곡에 사용하려면 중복 선택을 확인하게 합니다.

수용: 업로드 실패 시 처음부터 전부 다시 하지 않습니다. 파일을 가져왔다고 곧바로 팀이나 LIVE에 공개하지 않습니다. 원본 손상/암호/열기 실패를 명확히 알려주며 이전 정상 악보는 유지합니다. 제목만으로 서로 다른 곡을 자동 합치지 않습니다. 같은 해시 파일은 재사용을 제안하되 사용자가 새 메타데이터 버전을 만드는 선택은 지원합니다.

### F02. 곡 라이브러리와 검색
초성검색, 공백 무시, 한영 제목/별칭, 최근 사용, 즐겨찾기, 선택적 찬송가 번호+판본을 지원합니다. 검색은 다운로드된 메타데이터로도 작동합니다. 결과에는 제목, 키, 버전, 오프라인 유무를 표시합니다. ‘주 품에’와 ‘Still’ 같은 별칭은 사용자가 확인해 등록하며 플랫폼이 임의로 동일 곡이라 단정하지 않습니다.

수용: 초성/완성형/분해형 한글 테스트를 통과합니다. 전체 결과에 의미 없는 퍼지 매칭을 먼저 적용하지 않습니다. exact title → prefix → substring → aliases 순의 결정적 정렬을 기본으로 하고 초성 경로를 병행합니다. 게스트 검색은 허용 범위에 한정합니다.

### F03. 콘티와 대기곡
콘티는 예배 날짜/시간대, 제목, 곡 순서, 곡별 팀 버전, 연주 키를 보관합니다. 동일 곡이 두 번 등장해도 서로 다른 순서 항목 ID를 가집니다. 제목 대신 ID를 기준으로 필기와 상태를 연결합니다. 대기곡은 자주 즉흥으로 부르는 작은 모음입니다. 첫 테스트에는 15–30곡을 권장하되 숫자는 제품 제한이 아닙니다.

수용: 순서를 바꾸거나 대기곡을 추가해도 이미 열린 악보는 움직이지 않습니다. 콘티 복제 시 새 순서 항목 ID를 생성합니다. 지난 예배 팀 필기는 기본 복사하지 않고 선택적으로 가져오게 합니다. 개인 필기는 같은 버전에 다시 자동 표시됩니다.

### F04. iPad 악보장
세로/가로 한 페이지 중심, 수동 넘김, 확대/축소, 내 필기, 팀 필기 표시, 버전 선택, 콘티 복귀를 제공합니다. 두 페이지 보기와 Bluetooth 페달은 파일럿 필수 범위가 아닙니다. Pencil이 없는 사람도 보기와 손가락 필기 모드를 사용할 수 있습니다.

수용: 악보 보기 모드에서 손가락은 이동/페이지 제어에 쓰고 Pencil은 선택한 필기 모드에서 그립니다. 개인/팀 모드는 글자와 아이콘으로 구분합니다. 페이지 넘김은 다른 기기에 전송하지 않습니다. 전체화면 중에도 최소 현재 제목/키/연결 상태/새 안내 영역은 접근 가능합니다. 문서 다운로드/재연결 때문에 읽고 있는 악보를 로딩 화면으로 가리지 않습니다.

### F05. 개인 필기와 버전
필기 저장 키는 사용자 + 정확한 버전 + 페이지입니다. v1에 쓴 필기는 v1에 남고, v2/v3를 열어도 없어지지 않습니다. 올가미/영역 선택으로 한 획 또는 여러 획을 복사하고 다른 버전/페이지에 붙여넣고 이동합니다. 붙여넣기는 되돌릴 수 있고 원본은 보존합니다. 버전 선택은 새 기본 선호로 저장할지 사용자가 명시적으로 정합니다. 임시 미리보기는 선호에 영향을 주지 않습니다.

수용: 회전/확대/화면 크기 변경 후에도 필기 위치가 같습니다. 복사 붙여넣기가 원본을 지우지 않습니다. 붙여넣기 도중 취소하면 대상에 반영되지 않습니다. 기기 저장 완료 표시가 된 필기는 재시작 후 복원되어야 합니다. ‘기기 저장’과 ‘서버 동기화 완료’를 구분합니다.

### F06. 팀 손필기
진행/편집권 보유자는 펜/형광펜으로 동그라미, 화살표, 손글씨를 쓸 수 있습니다. 같은 순서 항목, 같은 버전을 보는 팀원에게 완성된 필기 변경을 전달합니다. 스트로크마다 네트워크 전송을 하지 않고 짧은 묶음 단위로 저장한 뒤 최신 revision을 전달합니다. 필기 시작 전에 ‘팀 필기 · 팀 전체 공개’가 명확합니다. 기본 시작 모드는 내 필기입니다.

수용: 다른 버전을 보는 사람에게 같은 좌표를 무조건 적용하지 않습니다. ‘팀 악보에 새 필기가 있습니다 → 미리보기’로 열며 현재 악보/개인 필기는 유지됩니다. 팀 필기 미리보기는 읽기 전용이고 닫으면 원래 페이지로 돌아갑니다. 개인 필기 지우개/되돌리기는 팀 필기를 지우지 않습니다. 팀 필기 업데이트로 멤버 페이지가 바뀌지 않습니다.

### F07. LIVE 곡 안내
밴드마스터는 최근/즐겨찾기/대기곡에서 곡, 팀 버전, 연주 키를 준비한 뒤 ‘팀에 곡 안내’를 누릅니다. 준비 단계는 다른 사람에게 보이지 않습니다. 서버가 수락해야 ‘안내됨’으로 표시합니다. 연주자는 비차단 알림에서 ‘악보 열기’를 눌러 자신의 선호 버전 또는 선호가 없을 때 팀 버전을 엽니다.

수용: 받기만 해서는 곡/키 확인 상태/페이지가 바뀌지 않습니다. 새로운 안내가 오면 가장 최근 안내로 하나만 갱신합니다. 지난 안내는 최근 10개 이력에서 직접 열 수 있습니다. 새 곡을 열지 않은 사람을 ‘틀렸다’고 경고하거나 강제로 이동시키지 않습니다. 같은 곡의 키 변경도 안내하고 확인을 요구합니다. 현재 연주 키와 내 악보 표기 키가 다르면 이를 분리해서 표시합니다.

### F08. 파일 준비와 오프라인
‘예배 준비 확인’은 이번 콘티 + 대기곡의 팀 버전과 내 선택 버전을 검증하여 내려받습니다. 다운로드 상태는 파일명/키/버전별로 확인할 수 있습니다. 미완성/손상 파일은 준비 완료에 포함하지 않습니다.

수용: 인터넷 단절 후 다운로드된 악보 보기, 페이지 이동, 내 필기 저장이 가능합니다. 미다운로드 파일은 열 수 없다고 설명하고 현재 악보를 유지합니다. 마지막 수신 안내는 시각/오프라인 표시와 함께 열 수 있습니다. 네트워크 복구가 현재 화면을 바꾸지 않습니다. 서버의 가장 최근 안내만 갱신하고 과거 안내를 순서대로 재생하지 않습니다.

### F09. 게스트와 공유
카카오톡은 메시지 수단으로 그대로 사용합니다. 앱에서 초대 링크/QR을 만들어 기존 채팅방으로 공유합니다. 파일럿 게스트는 설치된 iPad 앱에서 예배 범위로 참여합니다. 같은 링크를 새로 받은 사람에게 무제한 전체 교회 접근을 주지 않습니다. 만료/철회 시 온라인 접근이 차단되며 이미 받은 파일의 즉시 원격 삭제를 보장하지 않습니다.

수용: 초대 없이 임의 교회/콘티/스토리지 URL로 읽을 수 없습니다. 게스트 개인 필기는 기기 내에 저장하며 재설치/기기 교체 시 복원되지 않을 수 있음을 알려줍니다. 계정 전환이 필요한 장기 사용자에게는 정식 초대를 제공합니다.

### F10. 안전한 내보내기와 종료
허용된 악보를 원본 또는 개인/팀 필기를 명시적으로 선택해 PDF로 내보냅니다. 기본 포함은 ‘내 필기’, 타인의 개인 필기는 어떤 경로로도 포함하지 않습니다. 사용자가 소유/허가받은 범위에서만 내보내도록 안내합니다. 내보내기는 원본을 덮어쓰지 않습니다.

수용: 서버 비용/결제 문제, 세션 종료, 재연결이 이미 읽는 악보를 갑자기 닫지 않습니다. 로그아웃/앱 데이터 삭제에는 미동기화 필기 경고 및 안전한 내보내기 선택을 제공합니다. 법적 삭제 요구와 오프라인 접근의 한계는 보안 명세를 따릅니다.

## 4. 파일럿 제외
Android/iPhone 전용 UI, 웹 음악대, 결제, 교회 일정/봉사자 배정/채팅, 녹음, AI/OCR 자동 분할, 자동 조옮김, 악보 판매/공개 공유, 가사 송출, 박자계, MIDI/멀티트랙, 자동 페이지 넘김, AI 필기 위치 매칭, 여러 사람이 동시에 팀 캔버스 편집, 인터넷 없는 LAN 실시간 동기화.

## 5. 출시 전 약속의 한계
본 명세는 ‘버그가 없다’는 보장이 아닙니다. 검증되지 않은 구간을 표시하고, 정상 악보/저장된 필기를 보존하며, 실제 iPad/Apple Pencil과 여러 기기에서 장애 테스트를 통과시키는 것이 목표입니다. 자동 테스트 통과만으로 예배 현장 사용을 승인하지 않습니다.
