# WorshipCue
## 악보와 필기는 각자 편하게. 곡 안내와 팀 필기는 함께.

**WorshipCue는 한국어 찬양팀을 위한 iPad 디지털 악보장입니다.** 매주 PDF로 콘티를 준비하는 방식을 유지하면서, 악보 버전과 개인 필기를 보관하고 리허설 수정과 즉흥곡 안내를 팀에 전달합니다.

### 해결하는 문제
새 악보가 올 때마다 내 필기를 다시 찾는 불편, 팀 수정사항을 각자 옮기는 수고, 기도회에서 예정에 없던 곡을 안내하는 혼선을 줄입니다. 첫 대상은 iPad로 악보를 읽고 필기하며, 건반을 연주하는 밴드마스터가 진행하는 팀입니다.

### 네 가지 핵심 경험
**콘티와 악보 등록:** 개별 PDF와 여러 곡이 묶인 PDF 모두 지원합니다. 묶음 PDF에서는 곡별 페이지 범위를 지정합니다. 곡명·키를 확인하면 라이브러리에 저장됩니다.

**버전과 내 필기:** v1, v2, v3를 직접 선택합니다. 이전 악보와 필기는 그대로 남습니다. 필요한 필기만 선택해 다른 버전에 복사·붙여넣기·이동합니다. 자동 병합은 하지 않습니다.

**함께 보는 손필기:** 밴드마스터가 동그라미, 화살표, 손글씨를 공유합니다. 같은 악보 버전에는 바로 보이고, 다른 버전을 보는 연주자는 표시된 팀 악보를 미리봅니다. 개인 필기는 공개되지 않습니다.

**예배 중 곡 안내:** 밴드마스터가 곡과 키를 준비하고 ‘팀에 곡 안내’를 누릅니다. 연주자는 화면 알림을 보고 **직접 눌러** 곡을 엽니다. 선호 버전을 유지하며, 페이지도 각자 넘깁니다. 알림은 소리·진동 없이 가장 최근 안내 하나만 표시합니다.

### 연주를 방해하지 않는 기본 원칙
인터넷이 끊기면 실시간 안내는 멈추지만 다운로드된 악보와 개인 필기는 계속 사용할 수 있습니다. 재연결되어도 화면은 강제로 바뀌지 않습니다. 이번 콘티와 자주 부르는 대기곡을 미리 다운로드합니다. PDF의 키 표시는 자동 조옮김이 아닙니다.

### 시작 방식
**iPad 네이티브 파일럿 → 실제 리허설 검증 → 주일예배 검증.** 교회가 구독하고 연주자·게스트는 무료로 참여하는 모델을 검증합니다. Android, 채팅, 일정관리, AI 악보 분석, 자동 조옮김은 첫 버전에서 제외합니다.

**목표:** 모두가 같은 파일을 강제로 보게 하는 것이 아니라, 자기 악보를 편하게 쓰면서 팀의 변화는 놓치지 않게 하는 것.
